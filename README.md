# 오늘 입는 별자리 (Daily Fashion Fortune MVP)

매일 달라지는 별자리의 흐름을 오늘 입을 수 있는 색과 옷차림으로 제안하는 데일리 패션 운세입니다.

## 내 컴퓨터에서 실행하기

1. 이 폴더에서 터미널(PowerShell)을 엽니다.
   - 파일 탐색기에서 이 폴더를 연 뒤, 위쪽 주소창에 `powershell`을 입력하고 Enter를 누르면 됩니다.
2. 처음 한 번만 아래 명령어를 입력합니다. (필요한 파일을 받아옵니다. 1~2분 걸립니다.)
   ```
   npm install
   ```
3. 앱을 실행합니다.
   ```
   npm run dev
   ```
4. 브라우저에서 http://localhost:3000 을 엽니다.
   - 휴대폰 화면처럼 보려면 크롬에서 F12 → 왼쪽 위 휴대폰 모양 아이콘을 누릅니다.
5. 끝낼 때는 터미널에서 `Ctrl + C`를 누릅니다.

## 어떤 파일이 무슨 역할인가요?

| 파일 | 역할 |
|---|---|
| `app/page.tsx` | ① 첫 화면 (소개 + 별자리 선택) |
| `app/result/[sign]/ResultView.tsx` | ② 1초 전환 화면 → ③ 결과 화면 |
| `app/globals.css` | 화면 디자인 (색, 여백, 글자 크기) |
| `lib/fortune.ts` | 추천 로직. 나중에 실제 천체 데이터로 바꿀 때 이 파일만 고치면 됩니다. |
| `lib/seed.ts` | 날짜 + 별자리를 항상 같은 숫자로 바꾸는 함수 |
| `lib/date.ts` | 오늘 날짜, 계절 계산 |
| `data/signs.ts` | 12개 별자리 |
| `data/colors.ts` | 색 목록 (설명, 함께 쓰기 좋은 색) |
| `data/items.ts` | 아이템 목록 (맞는 계절, 활용 문장) |

## 추천 규칙

추천은 **별자리 성향 + 오늘의 달 + 패션 규칙**을 하나로 연결해 만듭니다. (`lib/fortune.ts`)

1. 오늘 날짜를 **한국 시간** 기준으로 정합니다. 한국 자정에 결과가 바뀝니다.
2. 그날 한국 시간 정오의 **실제 달 위치**를 계산해, 달이 머무는 별자리와 그 원소(불·흙·공기·물)를 구합니다. (`lib/sky.ts`, astronomy-engine 사용)
3. 내 별자리의 원소와 달의 원소가 같은지, 잘 어울리는지(불·공기 / 흙·물), 다른지를 봅니다.
4. 별자리마다 정해둔 스타일 테마 3개와, 달의 원소가 이끄는 테마를 함께 후보로 두고 비중에 따라 **오늘의 테마**를 정합니다. (`data/signs.ts`, `data/themes.ts`)
5. 테마 안에서 **컬러** → 그 컬러와 계절에 맞는 **아이템** → 컬러와 어울리는 **보조 컬러** 순서로 고릅니다.
6. 위에서 실제로 쓴 근거(달의 별자리, 원소 관계, 별자리 상징, 테마, 컬러·아이템)로 **추천 이유** 문장을 만듭니다.

- 같은 날짜 + 같은 별자리 → 항상 같은 결과 (새로고침해도 유지)
- 전날과 같은 컬러가 나오지 않도록 확인합니다.
- 테마 후보 안에서 무엇을 고를지는 날짜 규칙으로 정하며, 이 부분은 점성술적 근거로 설명하지 않습니다.
- 별자리 성향은 점성술의 상징을 패션으로 해석한 것이며, 과학적 성격 분석이 아닙니다.
- 코트·바지처럼 큰 아이템은 기본색(무채색 등)일 때만 추천합니다.
